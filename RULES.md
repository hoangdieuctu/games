1. Đảm bảo game title giống với tên ở index
2. Các game phải được cài đặt Google Analytics
3. Xóa bỏ các đoạn code dư thừa không được sử dụng
4. Sử dụng Tiếng Anh cho tên thư mục game
5. Các game phải có icon để share vào màn hình iPad
6. Mỗi game hãy tách html, css và js ra từng file riêng
7. Sau khi thay đổi phải test lại tính năng cũ đảm bảo không bug
8. Đảm bảo mỗi folder game có thể chạy độc lập, không có import từ folder trên
9. Khi game cần âm thanh thì làm Tiếng Việt và Tiếng Anh, làm giống như game little-world
10. Khi game có thể chơi online thì làm tính năng Voice Chat
11. Game online luôn có tính năng count down 30s, nếu người chơi AFK thì máy chơi thay
